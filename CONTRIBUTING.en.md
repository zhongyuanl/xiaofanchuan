# Contributing

**[简体中文](CONTRIBUTING.md) | [English](CONTRIBUTING.en.md)**

Bug reports, feature suggestions, compatibility reports and reference corrections are welcome. Search existing Issues before opening a new one.

For a bug, include the app version and build, operating system (macOS / Windows), OS version and architecture, package format, minimal reproduction steps, expected and actual behavior, and a redacted error or screenshot. Remove passwords, API keys, tokens, subscription URLs, real IPs and complete settings or browser profiles.

For a suggestion, explain the use case and desired behavior. Documentation pull requests are welcome; keep claims traceable and do not add unverified account-policy theories or protection guarantees.

This is currently a distribution and documentation repository. It does not contain the full application source, and the packages are not built by this repository's CI. These files cannot reproduce the complete binary. Source publication and licensing choices for the complete application remain separate decisions.
