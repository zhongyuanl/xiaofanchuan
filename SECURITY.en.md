# Security reports

**[简体中文](SECURITY.md) | [English](SECURITY.en.md)**

The project does not promise a security update schedule or isolation of every protocol. If you find credential exposure, permission or connection-control issues, stop using affected features, save your work and protect logs containing sensitive data.

Do not post secrets, subscription URLs, real IPs, unredacted logs or immediately exploitable details in public Issues. A dedicated private reporting channel is not configured. You may first post a contact request without vulnerability details and ask the maintainer for a private channel. This is not a claim that GitHub private vulnerability reporting is enabled.

Static inspection is not a full audit. Read the precautions on permissions, cleanup and privacy. Do not depend on this release for high-assurance network isolation.
