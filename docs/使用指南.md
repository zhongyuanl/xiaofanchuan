# 小帆船 v1.3.19 使用指南

## 1. 安装前准备

- Apple 芯片 Mac。APP 声明最低 macOS 13；未完成所有系统版本的兼容性测试。
- 从可信官方来源安装外部代理客户端，准备合法可用配置。
- 按需安装 Edge 或 Chrome、Claude 桌面端或 Claude Code。它们均不随小帆船安装包提供。
- 保存当前任务，备份 Claude Code 设置，并记录原系统语言、时区和网络 IPv6 配置。建议先在测试用户或虚拟机中验证。

DMG、ZIP、APP tar.gz 任取一种，安装到“应用程序”。不要直接在只读 DMG 中长期运行；不要同时运行多个小帆船副本。

## 2. 代理端口与通行

在外部代理客户端确认真实 HTTP/mixed 监听端口。常见 `7897` 仅为默认值，不适用于所有配置。进入小帆船“环境 → 网络”，填写实际值，选择目标地区；在 Clash 内手动确认 TUN、全局模式和系统代理状态。

小帆船的 `127.0.0.1:17897` 为本地水闸；应用转发到你填写的上游端口。二者不得互相回环。应用只监听本机，不应把代理端口暴露给局域网。

等待出口检测完成，查看代理连通性、地区、ASN 和质量信息。若阻断，按界面原因逐项排查；查询失败、未知属性、缓存和来源差异不代表服务端封禁。第三方风险分只是本地参考阈值，不能当作 Anthropic 官方规则。

开启“安全护航”后，通过小帆船提供的入口启动目标客户端。已经从其他位置启动的软件可能不带相同参数，应先保存并关闭再从应用入口启动。不要把开启 TUN 或水闸的状态当成全部应用已受控的证明。

## 3. 浏览器与 Claude Code

安全浏览器使用专用资料目录，与平常的浏览器资料分开。请自行安装 Edge 或 Chrome。找不到可用浏览器或水闸未就绪时，v1.3.19 的启动脚本会拒绝继续；不要为绕过提示而改用系统默认浏览器登录。

首次登录遵循官方 OAuth 流程，不需要向小帆船提供账号密码或 API Key。Claude Code 的 BROWSER 启动脚本和代理环境由相关配置操作生成；检查实际路径和设置后再使用。

Claude Code 配置写入会先创建 `~/.claude/settings.json.guard-backup-时间戳`，保留最近 5 份。既有 JSON 不能解析时停止写入。程序会处理部分代理、网关和环境变量；`sk-ant-` 前缀保留规则只是字符串检查，不保证所有自定义认证方案兼容。使用第三方网关或企业配置者，先备份并比较写入前后差异。

## 4. 可选环境操作

“一键配置”可能同时改变系统语言、时区、IPv6 和 Claude Code 设置；时区流程包含管理员授权及 sudoers 规则写入。请先阅读[注意事项](注意事项与隐私说明.md)。仅需检查网络时，不必运行全部环境治理或清理操作。

“重建浏览器资料”会清除专用资料中的登录状态等数据。“封号善后”可能删除 Claude Code 凭据、历史备份、会话、钥匙串条目和桌面端本地资料，并重建设备标识。它不能解除封禁，也不能保证账号互不关联，误操作可能导致无法恢复的数据丢失。

## 5. 结束、升级和恢复

- 先保存任务，再关闭护航或退出应用。关闭护航会中断相关代理连接；退出时的清理逻辑可能结束 Claude、独立浏览器及 Claude Code 终端进程。
- 升级前退出旧版，再替换 APP。保留设置快照；更新并不自动回滚已有系统配置。
- 恢复 Claude Code 设置：关闭相关客户端，另存当前设置，从自己确认的 `guard-backup` 快照恢复，并检查其中代理/BROWSER 路径。不要把含凭据的快照发到 Issues。
- 停用小帆船后，若不再需要其启动脚本，移除自己确认由它写入的 BROWSER/代理设置，避免残留 `17897` 造成连接失败。保留其他软件的配置。
- 系统语言、时区、IPv6 恢复为你记录的原值。sudoers 规则及历史特权助手需要管理员逐项确认后移除，不能把删除 APP 当成权限清理完成。

## 6. 卸载

退出小帆船并保存其他客户端任务，备份配置。删除“应用程序”中的 APP 仅移除应用本体。用户资料、脚本、Claude 设置、全局语言/时区、IPv6、sudoers 规则及曾经部署的系统级助手不会因此自动恢复。

用户资料通常在 `~/Library/Application Support/ClaudeGuard/`，部分历史助手资料在 `/Library/Application Support/ClaudeGuard/`。先查看内容和归属再处理；不要直接删除系统级目录、盲目执行开发工程里的 TW 虚拟机脚本或重置整机 PF。既有特权服务与网络规则建议交由熟悉本机配置的管理员处理。

## 7. 常见问题

**提示无法验证开发者？** 本版没有 Apple 公证。先核对来源、SHA-256 和系统提示，按系统正常流程处理；不要关闭整机安全机制。

**Intel Mac 打不开？** 此发行是 arm64，Rosetta 不能让 Intel Mac 运行 arm64 程序。本次没有 Intel 构建。

**界面正常，但 Claude 无法登录？** 检查真实代理端口、外部客户端、目标入口是否由本应用启动，再查看官方登录信息。网络检查无法确定账号资格、支付状态或解除服务限制。

**IP 分数或地区不一致？** 数据库可能更新延迟，代理节点也可能变化。未知不应手动解释为安全；确认代理实际出口并等待重新检测。

**关闭后其他程序也退出？** 当前清理逻辑按进程名/命令特征匹配，可能影响其他 Claude 会话。使用前保存工作；这也是当前版本限制。

**反馈按钮打不开正确仓库？** 本次二进制仍含旧地址，通过本仓库 Issues 提交。检查更新面板也不是实时联网版本检查。
