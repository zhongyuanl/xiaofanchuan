# 注意事项与隐私说明

适用于小帆船 v1.3.19，说明依据本地代码和安装包静态检查。未进行干净系统的完整安装/卸载、全协议防泄漏或所有功能端到端验收。

## 使用资格与保护范围

小帆船不是 Anthropic 官方产品，也不是账号服务或防封服务。代理出口、住宅标签、Git 邮箱、npm 源、语言和设备标识都不能证明或改变实际用户资格；不应借助本程序规避服务限制。内置帮助和旧日志中的“秒封”“永久拉黑”“零泄漏”等说法不能当成官方政策或已验证结论，403 也可能有多种原因。账号、申诉和退款以官方当时页面与个案回复为准。

护航涉及本地代理和周期检测，不是经过完整验收的整机隔离产品。直接启动的软件、绕过代理的协议、IPv6、DNS/WebRTC、网络切换、崩溃重启等情况需要独立验证。不要用于要求高保证隔离的场景。

## 可修改与删除的数据

| 操作 | 实际影响 |
|---|---|
| Claude Code 配置 | 写入 settings.json、代理/BROWSER 等环境，生成脚本；v1.3.19 创建设置快照并最多保留 5 份 |
| 地区快捷配置 | 可能修改全局语言、区域、时区，停用 IPv6，调整 Claude Code 环境 |
| 时区管理员快捷通道 | 可能写入 `/private/etc/sudoers.d/claudeguard`，留下持久免密权限规则；安装包拖入应用目录不等于权限配置只影响 APP |
| 浏览器资料重建 | 删除并重建专用浏览器资料，登录状态与资料可能丢失 |
| 封号善后/深度清理 | 可删除凭据、备份、会话、钥匙串与桌面端资料，修改设备标识；不能靠设置快照完整恢复 |
| 退出与异常清理 | 按进程名/命令特征终止相关客户端和终端，可能影响本应用之外的会话 |
| 外部软件安装入口 | 可能下载安装 Clash、Chrome、Claude、Node/Claude Code，均有独立来源和许可；本版部分下载链接固定到旧版本 |

以上是对现有行为的披露，不是要求用户执行这些操作。修改前自行备份；不要对未知规则、凭据或系统目录批量清理。

## 联网与隐私

应用包含 IP/地理位置/网络属性探测，并非纯离线工具：

- IPPure：`my.ippure.com`；ipapi.is：`api.ipapi.is`；ip-api：`ip-api.com`。
- Scamalytics：`scamalytics.com`；其他配套探针/页面可使用 `ipwho.is`、`api.ipify.org`、`myip.ipip.net`。
- 下载或帮助入口可能访问 GitHub、Google、Microsoft、Anthropic 和 Node.js 官方站点。

这些服务可看到请求来源 IP；部分查询会在 URL 中携带待查询的出口 IP。某些本机原始出口查询使用直连或明文 HTTP，服务方和传输链路可能看到实际 IP 及查询信息。不要将本应用理解为“任何时候均无直连请求”。各第三方服务的可用性、隐私条款、限额和数据准确性由其各自决定。

日志与配置保存在本地用户或系统级 ClaudeGuard 目录；现有代码含用户目录扫描和系统级文件写入路径，不承诺多用户隔离。日志、设置快照可能包含 IP、路径、认证环境变量等敏感内容。提交问题前自行脱敏，勿上传 API Key、Token、订阅 URL、完整浏览器资料、钥匙串或未清理日志。

## 已知限制

- arm64 单架构；ad-hoc 签名；未做 Developer ID 签名与公证。
- 未确认全部 macOS 13+ 的运行兼容性；干净系统缺少外部软件和旧助手时可能出现功能差异。
- 内置反馈按钮仍指向旧的 `alan/ClaudeGuard` 地址；请用实际发布仓库 Issues。
- 内置检查更新展示固定文本，不是真正的联网更新检查。
- 本次静态检查不等同于完整安全审计或生产隔离验收。请优先在测试环境使用，并保留恢复路径。
