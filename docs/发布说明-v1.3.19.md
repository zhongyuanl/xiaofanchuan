# 小帆船 v1.3.19 · Build 149

**[简体中文](发布说明-v1.3.19.md) | [English](RELEASE_NOTES.en.md)**

本次公开发行提供同一个 macOS Apple Silicon 应用的 DMG、ZIP、APP tar.gz 三种格式。版本日期：2026-10-22。

## 本版变化

- 写入 Claude Code 设置前保存带时间戳快照，最多保留最近 5 份；已有 JSON 无法解析时停止写入。
- 凭据处理保留 `sk-ant-` 前缀内容；这只是前缀判断，不验证密钥是否合法、有效或为官方签发。
- 安全浏览器启动脚本检查本地 `17897` 水闸和可用受控浏览器，条件不满足时提示并退出。
- 调整代理设置入口，引导用户打开 Clash 手动设置。
- 调整未知分数展示，补充应用内帮助信息。

这些变化依据当前源码与已有本地版本记录整理，未对所有用户路径重新完成端到端测试。旧日志中的防封推断、服务风控与退款结论没有作为已验证事实发布。

## 安装

1. Apple Silicon Mac；应用声明 macOS 13.0 起，未完成全版本兼容性测试。
2. 在 Assets 下载三种格式之一，将解压或镜像中的 `.app` 放入“应用程序”。APP 在 GitHub 以 tar.gz 封装下载。
3. 安装自己的外部代理客户端与按需使用的浏览器/Claude 客户端。
4. 参照[使用指南](使用指南.md)设置真实代理端口、检查出口，再从应用内启动目标入口。

## 使用前必须了解

- 本版为 ad-hoc 签名，未获 Apple Developer ID 签名及公证；不包含 Intel 构建。
- 不提供节点、账号或订阅；不承诺防封、解封、匿名、服务资格或整机全部流量保护。
- 环境操作可能修改语言、时区、IPv6、Claude Code 设置和 sudoers 权限规则。
- 清理功能可能不可逆删除登录资料；退出应用可能关闭其他 Claude 会话，请先保存任务。
- 网络检查会访问第三方服务，部分原始出口探测可能直连或使用 HTTP。
- 内置反馈按钮仍是旧地址，请使用实际仓库 Issues；检查更新并非联网自动更新。

本次保留用户确认版本的二进制，不为修改反馈地址或补充资源而重编译、重签安装包。DMG 与用户提供文件的 SHA-256 相同。
